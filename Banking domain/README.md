# 📊 Banking Customer Analysis – End-to-End Data Analytics Project

## 🔍 Project Overview

This project demonstrates a **real-world, corporate-style data analytics workflow**, showcasing how raw banking data can be transformed into **actionable business insights**.

It represents the complete journey of a **Data Analyst** — from data preparation and database design to **interactive dashboards**.

The goal of this project is to simulate how analytics teams work in organizations by integrating **SQL and Power BI** into a complete analytics pipeline.

---

## 🎯 Project Objectives

* Transform raw banking data into **structured and analysis-ready format**
* Analyze **customer demographics and financial behavior**
* Identify patterns in **loan distribution and balance trends**
* Answer **business-related queries using SQL**
* Present insights through **interactive dashboards**

---

## 🛠️ Tools & Technologies

* **SQL (MySQL / SQL Server)** – Database creation, querying, and data transformation
* **Power BI** – Dashboard creation and data visualization
* **Excel / CSV** – Data source for initial dataset

---

## 📁 Project Structure

### 1️⃣ Data Preparation & Database Setup (SQL)

* Created a relational database: `banking_dashboard`
* Designed table: `banking_data`
* Inserted structured customer data
* Ensured proper data types and integrity

---

### 2️⃣ Data Transformation using SQL

* Created a **SQL View (`dashboard_view`)**
* Generated:

  * Age groups for segmentation
  * Year column for trend analysis
* Prepared clean dataset for visualization

---

### 3️⃣ Business Analysis Using SQL

📄 **SQL Queries**

Key business insights derived:

* Total number of customers
* Total and average account balance
* Loan distribution among customers
* Regional customer distribution
* Customer segmentation based on age

All queries are written with **clear logic and aggregation functions**.

---

## 📊 Data Visualization & Dashboarding (Power BI)

📊 **Banking Customer Analysis Dashboard**

The dashboard provides a **complete overview of customer and financial data**.

### 🔷 Key Dashboard Features:

* KPI Cards:

  * Total Customers
  * Total Balance
  * Average Balance
  * Loan Count

* Visualizations:

  * Bar Chart → Customer distribution (Age & Gender)
  * Donut Chart → Region distribution
  * Funnel Chart → Loan status
  * Line Chart → Balance trend over time
  * Table → Detailed customer data

* Interactive Filters:

  * Gender
  * Age
  * Region
